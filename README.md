# Visualisasi Data: Anime Naruto (Rating & Votes)

Repository ini berisi kode HTML dan JavaScript menggunakan pustaka **Chart.js** untuk memvisualisasikan data *Rating* dan *Votes* dari 10 episode pertama Season 3 Anime Naruto. 

Proyek ini dibuat untuk memenuhi tugas **ETS Visualisasi Informasi**.

## Fitur Visualisasi
* **Kombinasi Bar & Line Chart:** Menampilkan gabungan *bar chart* dan *line chart* dalam satu grafik (*stacked combined*).
* **Interaktif & Animasi:** Dilengkapi dengan animasi *delay* saat grafik dimuat dan fitur *tooltip* interaktif saat mengarahkan kursor ke titik data.
* **Responsive Design:** Tampilan grafik menyesuaikan ukuran layar (*responsive container*).

## Teknologi yang Digunakan
* HTML5
* JavaScript (ES6)
* [Chart.js](https://www.chartjs.org/) (via CDN)

## Cara Menjalankan
1. *Clone* atau *download* repository ini.
2. Buka file `Jeremy Brasil Hasiando_06311940000082_ETS Visualisasi Informasi.html` langsung di *browser* (Chrome, Edge, Firefox, dll.).
3. Pastikan perangkat terhubung ke internet untuk memuat pustaka Chart.js dari CDN.
